# 🏦 Bank Loan Analysis Project

## 📌 Overview
This project focuses on analyzing bank loan data to extract meaningful insights related to loan applications, funded amounts, and repayments. The goal is to understand customer behavior, loan performance, and key financial metrics.

---

## 🎯 Objectives
- Analyze total loan applications
- Track Month-to-Date (MTD) loan trends
- Calculate total funded amount
- Evaluate total amount received
- Identify patterns in loan distribution

---

## 🛠️ Tech Stack
- **Python**
- **Pandas** – Data manipulation
- **NumPy** – Numerical operations
- **Matplotlib & Seaborn** – Data visualization
- **Plotly** – Interactive charts

---

## 📂 Dataset
- File: `bank_loan_data.csv`
- Contains loan-related information such as:
  - Loan ID
  - Issue Date
  - Loan Amount
  - Payment details

---

## 🔍 Key Analysis Performed

### 1. Data Understanding
- Checked number of rows & columns
- Inspected data types
- Generated statistical summary

### 2. Data Cleaning
- Converted `issue_date` to datetime format
- Handled missing/incorrect values

### 3. KPI Metrics

#### ✅ Total Loan Applications
- Count of total loan records

#### 📅 MTD Loan Applications
- Loans issued in the latest month

#### 💰 Total Funded Amount
- Sum of all loan amounts

#### 📊 MTD Funded Amount
- Loans funded in the current month

#### 💵 Total Amount Received
- Total repayments received from customers

---

## 📈 Insights
- Identified overall lending volume
- Tracked monthly growth trends
- Evaluated financial performance of loans
- Helped in understanding repayment behavior

---

## 📊 Visualizations
- Loan trends over time
- Funded vs received amount comparison
- Distribution plots using Seaborn & Plotly
